# Team profile submissions

This directory stores pending team profile submissions received through the LAM+ Team Portal.

Each submission consists of:
- `<slug>.json`
- `<slug>.png`

These files are reviewed manually before updating:
- `assets/data/team-pt.yml`
- `assets/data/team-en.yml`
- `assets/img/team/`

Files in this directory are not considered published team data.
